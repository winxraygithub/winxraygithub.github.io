一、大陆白名单的本质与核心价值

1.1 逆向思维的流量管理哲学

与传统"黑名单封锁"模式截然不同，白名单采用"例外放行"策略：
- 精准代理：仅对名单外域名启用代理通道
- 本地直连：所有中国大陆服务保持原始网络路径
- 混合路由：实现单设备同时存在国内外两种连接模式

1.2 三重核心优势解析

速度优化：北京用户访问淘宝时，数据包不再绕道东京服务器，延迟从300ms降至50ms
安全增强：工商银行APP的交易数据完全规避境外服务器中转风险
资源节约：代理服务器流量消耗减少60%-80%，显著降低服务费用

二、专业级配置全流程指南

2.1 基础规则配置（图文辅助说明）

  1. 规则组创建

    • 进入"配置文件"→"编辑本地文件"
    • 添加[Rule]区块并设置匹配逻辑：
      DOMAIN-SUFFIX,baidu.com,DIRECT DOMAIN-KEYWORD,alipay,DIRECT GEOIP,CN,DIRECT FINAL,PROXY

  2. 智能分流策略

    • 使用GEOIP,CN自动识别中国IP段
    • 配合DOMAIN-SUFFIX补充特定域名
    • FINAL指令确保非匹配流量默认代理

FAQ

SSR 节点和 V2Ray 节点可以混合使用吗？
可以，但要使用支持多协议的客户端，如 Clash、Sing-box、Mihomo 等。这类客户端能在同一配置文件中加载不同协议的节点，通过规则分流让 SSR 与 V2Ray 同时工作。
VMess 的 WebSocket + TLS 配置有哪些好处？
WebSocket + TLS 可伪装为普通 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可以在高封锁网络中保持稳定、高速和安全的网络访问体验。
Sing-box 是否兼容 Clash 配置文件？
部分兼容。Sing-box 支持从 Clash 订阅转换工具导入节点，但配置语法略有不同。建议使用第三方订阅转换器，如 sub-converter，将 Clash 格式转换为 Sing-box JSON 格式使用。
SSR 的混淆方式选择有什么讲究？
混淆方式决定流量伪装特性，不同方式适应不同封锁环境。常用方式如 tls1.2_ticket_auth 模拟 HTTPS，http_simple 模拟 HTTP 请求，根据环境选择可提高抗封锁能力。
WinXray 延迟检测如何提高网络稳定性？
WinXray 定期测速节点延迟，并结合策略组自动切换到延迟最低节点。这样可保证网页、视频和游戏流量稳定快速访问，减少卡顿和掉线，提高整体网络体验。
V2Ray 与 Clash 有什么区别？
V2Ray 是一款代理核心工具，提供底层网络传输和加密支持；而 Clash 是一个多协议客户端，可以整合 V2Ray、Trojan、Shadowsocks 等多种协议。简而言之，V2Ray 负责“传输”，Clash 负责“管理与分流”。
V2Ray QUIC 传输适合什么网络环境？
QUIC 基于 UDP 支持多路复用和零握手，降低延迟，提高吞吐量。适合高丢包、不稳定网络环境，可保证视频、游戏和即时通讯流量的稳定性和流畅体验。
Mellow 使用透明代理时如何避免 DNS 泄露？
在 Mellow 中启用 fake-ip 或内置 DNS 解析功能，并将上游 DNS 指定为 DoH/DoT 服务，确保所有 DNS 请求通过代理转发而非本地解析，从而避免 ISP 或本地网络捕获实际访问域名。
Matsuri 节点延迟排序功能如何使用？
Matsuri 会自动测试节点延迟，并根据结果排序。用户可以选择延迟最低的节点使用，从而优化访问速度和稳定性，尤其适合游戏、视频和海外网站加速。
Sing-box 的分流规则可以按端口分配节点吗？
支持。用户可通过端口号匹配流量，将不同应用的流量分配到指定节点，实现精准分流。结合策略组使用，可优化访问速度和网络稳定性。
